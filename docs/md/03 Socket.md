+ 什么是Socket？

&nbsp;在计算机通信领域，Socket被翻译为“套接字”，它是计算机之间进行通信的一种约定或一种方式。本质是编程接口（API），对TCP/IP的封装。

+ 用"寄快递"来类比

&nbsp;把一次网络聊天想成**寄快递**：

- **TCP/IP** = 整个快递公司的"运作规则手册"
  
  - **IP**：规定包裹上写什么地址（哪台机器、哪个端口），怎么在路网上选路线 → 解决"送到哪"。
  - **TCP**：规定怎么打包、怎么编号、丢了怎么重发、到了怎么排序 → 解决"可靠送到、不乱"。
  - 它是一堆**看不见的约定/规范**，规定了报文的格式和做法。

- **Socket（套接字）** = 你家门口的**邮箱 / 取件口**
  
  - 你的程序（应用程序 A）想寄东西，不用自己跑去邮局，只要把数据"塞进" Socket，剩下的分包、寻址、重传全是 TCP/IP 替你干。
  - 对方也是从他自己的 Socket 把数据取出来。
  - 它是操作系统给你的一个**接口（API）+ 通信端点**，是你"摸得着、能调用"的东西。

&nbsp;所以一句话区别：**TCP/IP 是规则，Socket 是调用这套规则的工具。没有 TCP/IP，Socket 没东西可管；没有 Socket，你的程序也没法直接用 TCP/IP。**

+ 数据传输方式
  
  + STREAM
    
    + 面向连接
    
    + 数据可以准确无误地到达另一台计算机，如果损坏或丢失，可以重新发送，但效率相对较慢
  
  + DGRAM
    
    + 无连接的数据传输方式
    
    + 计算机只管传输数据，不作数据校验，效率比STREAM高

+ 服务器端程序的编写步骤
  
  + 调用socket()函数创建一个用于通信的套接字
  
  + 给已经创建的套接字绑定一个端口号，这一般通过设置网络套接字地址和调用bind()函数来实现
  
  + 调用listen()函数使套接字成为一个监听套接字
  
  + 调用accept()函数来接受客户端的连接
  
  + 处理客户端的连接请求
  
  + 终止连接
- 客户端程序编写步骤：
  - 调用socket()函数创建一个用于通信的套接字
  - 通过设置套接字地址结构，绑定服务器的IP地址和端口号
  - 调用connect()函数来建立与服务器的连接
  - 调用读写函数发送或接收数据
  - 终止连接
